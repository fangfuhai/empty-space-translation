# 空格翻译 1.1.2 — 2026-11-09

构建标识 `ST-20261109-V112-Startup`。

- “我会的”整句精确译为 `I will.`，中文句号及感叹号版本同样支持，用户词库仍优先。不会对子串强行替换。
- 补充意愿、能力和可能性的区分：我会检查 → I will check；我会游泳 → I can swim；我可能会 → I might。否定、条件及不确定性需保留，长句仍按上下文翻译。
- 修复自动启动只检查一次 Ollama、未就绪就停住的问题。现在启动时自动连接服务；无法连接则尝试在后台启动已安装的 `ollama serve`，最多探测 30 次，每次最多 2 秒，间隔 1 秒，然后预热已有模型。整个自动准备最多 3 分钟，退出时取消，不无限重试，也不自动下载模型。
- 模型未安装、服务无法启动或超时会明确提示，允许手动重试。保留用户暂停状态，不因预热成功擅自恢复暂停的翻译。

## 升级

从托盘退出旧版，运行 `release-v1.1.2/SpaceTranslate.exe` 或完整解压本版 ZIP。保留全部运行文件，复用原配置、模型和词库。

**若之前已开启自启动，请在新版中取消后重新勾选一次**，将启动项从旧目录更新到新版目录。之后登录 Windows 应自动准备已有模型，无需再点“准备模型”。第一次缺少 Ollama 或配置所指的模型时，仍需安装/准备；这不属于已安装模型的常规启动流程。
