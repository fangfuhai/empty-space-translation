# 空格翻译 1.1.0 Preview · 词库与多语种试用版

本版在中英翻译基础上增加自定义术语、目标语言选择和故障日志导出，面向愿意协助验证新功能的用户。**请作为 Pre-release 发布，日常中英使用仍可选择 1.0.15。**

作者：**linthon · 方赋海**  
程序集版本：**1.1.0**  
构建标识：`ST-20261001-V11-Preview`

## 新增功能

### 自定义 TXT 词库

在主窗口或托盘点击“导入词库”，导入 UTF-8 文本。每行包含三列：目标语言代码、原词、指定译法，使用 **Tab 制表符**分隔。

```text
en	滚珠轴承	ball bearing
en	起订量	minimum order quantity
zh	ball bearing	滚珠轴承
fr	滚珠轴承	roulement à billes
```

长词优先、区分大小写，不同目标语言分别匹配；不自动生成反向词条。指定译法优先于内置短语，整句完全命中时可本地输出。最多 1000 条，每个原词/译法最多 200 字。格式或重复冲突检查失败时保留旧词库；检查通过后确认替换，从下一次翻译生效。

数字、金额、日期和带数字的型号仍由事实保护模块负责，不允许通过词库覆盖这些信息。导入词库保存在个人应用数据目录，不随故障日志导出。

### 多语种选择

可在主窗口、托盘菜单或右下角提示框选择英语、简体中文、法语、土耳其语、泰语、日语、俄语、西班牙语、韩语。

- 选择会保存，并作用于下一次双空格翻译，不改变已经开始的任务。
- 双空格读取全文，不再要求来源文字包含中文。
- Ctrl+Alt+E 固定译英文、Ctrl+Alt+Z 固定译中文、Ctrl+Alt+P 暂停/恢复。
- 中英继续使用原有自动替换条件；新增七种语言仅交付剪贴板供核对，不自动替换。
- 点击提示框切换语言可能改变焦点，当前任务会按原有规则转为剪贴板交付。

**新增语言仍属实验功能。** 实测土耳其语出现过否定方向错误，韩语出现过混入其他语言的片段。模型成功返回文本不代表语义正确；当前未更换用户模型或增加内存参数。需要稳定中英翻译的用户可继续使用 1.0.15。

### 故障日志导出

点击“导出日志”即可保存 TXT，包含版本、目标语言、词库条数、任务阶段、耗时和错误类型等，方便维护者定位问题。

默认不导出原文、译文、窗口标题、词库内容、完整配置或旧诊断日志，不自动上传或发送。日志按大小轮转；关闭 LogDiagnostics 时不记录任务事件。反馈翻译质量问题请另附去隐私的测试原文及译文。

## 安装与升级

需要 Windows 10 / 11 x64、本机 Ollama、本地模型和 .NET 8 Windows Desktop Runtime x64。完整解压，退出旧程序，再运行 `SpaceTranslate.exe`；不能只复制 EXE，DLL、deps.json 和 runtimeconfig.json 必须保留。

两个版本共用 `%LOCALAPPDATA%\SpaceTranslate` 下的个人配置，程序不支持同时运行两个版本。切回稳定版前退出试用版；词库和目标语言是试用版功能，稳定版不会因此获得这些功能。
