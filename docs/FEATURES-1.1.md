# 1.1.0 功能试用版

程序位于 `release-v1.1.0-preview/SpaceTranslate.exe`。保留同目录全部配套文件。退出旧版后再启动试用版；1.0.15 稳定版本仍保留。

## 自定义 TXT 词库

主窗口或托盘菜单点“导入词库”。选择 UTF-8 TXT，程序先检查全部内容，显示条目数，再由用户确认替换当前词库。格式错误不会替换原词库。

每行三列：**目标语言代码、原词、指定译法**，列之间使用真正的 Tab 制表符，不是空格或字面上的 `\t`。以 `#` 开头的行是注释。可从 [词库模板](glossary-example.txt) 修改，也可用表格编辑三列后保存为 UTF-8 制表符文本。

| 代码 | 语言 |
| --- | --- |
| en | 英语 |
| zh | 简体中文 |
| fr | 法语 |
| tr | 土耳其语 |
| th | 泰语 |
| ja | 日语 |
| ru | 俄语 |
| es | 西班牙语 |
| ko | 韩语 |

规则：长词优先、区分大小写；英文词按字母数字边界匹配，中文术语可在句中匹配。不同语言单独匹配，不自动反向生成条目。若希望 `bearing` 译回 `轴承`，另加 `zh` 对应行。词库译法优先于内置短语，整句完全命中时可直接本地输出。

最多 1000 条，每个原词/译法最多 200 字；同一目标语言的原词不能重复。数字、金额、日期、带数字的型号由原有保护模块处理，不允许词库覆盖这些事实；例如可定义“轴承”，不能定义将“100美元”改为其他金额。保护占位符缺失/重复仍会拒绝交付。

导入后保存在 `%LOCALAPPDATA%\SpaceTranslate\glossary.txt`，下一次翻译生效；重启会加载。导入只有注释的空模板可清空自定义词库。原文件由用户自行保存，程序不会修改导入来源文件。不要把私人行业词库或客户名称上传到公开仓库。

## 多语种选择

主窗口下方、托盘“目标语言”菜单和右下角提示框均可选择。也可从托盘点击“选择目标语言（右下角）”调出选择框。

- 选择会保存，并作用于**下一次双空格翻译**；进行中的任务仍使用开始时的语言。
- 双空格读取全文；这版不再只接受含中文的输入，来源语言由模型理解。
- Ctrl+Alt+E 固定译英文，Ctrl+Alt+Z 固定译中文；Ctrl+Alt+P 暂停/恢复不变。
- 点击提示框可能改变焦点，正在翻译的任务会按原有规则失去自动替换资格，完成后交付剪贴板。
- 中英方向继续使用原有自动替换规则。新增七种语言标为试用，**仅交付剪贴板**，请核对后粘贴；不自动发送。

当前仍使用原配置模型，未下载更大模型、增加上下文或并发。实测新语言能返回结果，但不能保证语义质量：土耳其语样本出现过否定方向错误，韩语样本出现其他语言片段。中文残留检查不能发现所有这类错误，日语包含合法汉字，也不能直接套用“禁汉字”规则。新增语言尚未通过母语者验收，不能作为已完成语言质量验证的正式发布。

## 导出故障日志

主窗口或托盘点击“导出日志”，选择保存位置即可生成 TXT。不会自动上传或发送。

导出包含版本、操作系统/.NET 版本、目标语言、词库条数、任务阶段、耗时、错误类型等。只导出新的结构化 `support.log`，不导出输入/译文、窗口标题、Prompt、词库内容、模型输出指纹、完整配置、旧诊断日志或私人 EXE 路径。

日志有大小轮转：support.log 约 256 KiB，最多保留当前及上一份；原 diagnostics.log 约 512 KiB，也最多保留当前及上一份。若用户关闭 LogDiagnostics，任务事件不会记录，导出仍有基础版本信息。

反馈时请补充：触发方式、目标语言、预期行为、实际提示、是否切窗/继续输入、能否重复出现。翻译质量问题需要用户另行提供去隐私的原文和译文，默认日志无法还原聊天。
