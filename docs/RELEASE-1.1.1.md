# 空格翻译 1.1.1 — 2026-10-13

构建标识：`ST-20261013-V111-Reliability`。基于 1.1.0 功能版修复近期商务翻译反馈，保留蓝色界面、自定义词库、多语种选择和日志导出。中英为本轮验证方向，新增七种语言仍属试用。

## 本次更新

- “好几千块钱”“几百美元”等作为完整模糊金额保护，不把“几千”猜成具体数值；不做汇率换算。“模块”“单元”“一块蛋糕”“几千元件”不当作人民币。此类中文模糊金额目前限中英方向，其他方向会明确提示。
- 金额代码不区分大小写，`20rmb` 整体保留为 `RMB 20`；无币种价格 `260`、`380左右` 不添加币种。请求只提供保护项的类型，降低模型展开或省略占位符的概率，仍拒绝缺失、重复和新增金额。
- `27Q4-28Q1` 作为完整季度区间保护，不擅自补世纪。
- 多行内容按原行使用必填字段翻译，恢复空行；缺少标题或任一非空行会失败重试。清理模型生成的 `<br>`、`<dr>` 换行标记，原文明确含此类标签时保留其字面内容。最多 80 个非空行，超出请分段。
- 新增整句快速回复：“稍等”“稍等一下”“请等待一下”“请稍等”“没问题”，含中文句号版本。只匹配完整原文；长句和否定句仍交给模型，不做子串替换。
- 经作者确认，业务缩写 `qta` / `QTA` 默认译为 `expedited sample`（加急样品）；“唛头”译为 `shipping mark`。这不是对所有行业 QTA 的通用解释；用户导入的对应词条优先。
- 增加“登录 Windows 后自动启动（后台运行）”开关，默认关闭。只在用户勾选时注册当前用户启动项，无需管理员权限；取消勾选删除本程序启动项。后台启动仍会检查本地 Ollama；不会自动下载模型。

## 使用与升级

1. 从托盘退出旧版，完整解压新 ZIP，运行 `SpaceTranslate.exe`。EXE、DLL、deps.json 和 runtimeconfig.json 必须在同一目录。
2. 依赖 Windows 10/11 x64、.NET 8 Windows Desktop Runtime x64、本地 Ollama 和已准备的模型；本包不是自包含版。复用现有个人配置和词库，不会替换模型。
3. 双空格翻译全文，目标语言由下拉框选择。Ctrl+Alt+E 译英文、Ctrl+Alt+Z 译中文（先选中文字），Ctrl+Alt+P 暂停/恢复。
4. 原输入框未编辑且仍有焦点时核对后替换；切窗或继续输入后交付剪贴板。软件不自动发送消息。
5. 开机启动请先将程序放在长期保留的目录，再勾选主窗口底部开关；搬动目录或升级到新目录后，取消并重新勾选以更新路径。实现为当前用户 Run 项 `SpaceTranslate`，命令是带引号的 EXE 路径加 `--background`，并非系统服务。Ollama 的开机启动需由 Ollama 自身管理。
