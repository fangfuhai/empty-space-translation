# 空格翻译 1.0.15 · 海蓝稳定版

写完中文，空格两下。

空格翻译是一款基于本地 Ollama 的 Windows 后台翻译工具，适用于日常聊天和商务沟通。此版本面向日常中英翻译，采用统一的海蓝色界面与空格键 Logo。

作者：**linthon · 方赋海**  
版本：**1.0.15 / FIX10**  
构建标识：`ST-20261001-FIX10-Blue`

## 主要功能

- 快速双空格读取当前输入框全文，含中文时译成英文。
- Ctrl+Alt+E 将选中文字译成英文，Ctrl+Alt+Z 译成简体中文。
- Ctrl+Alt+P 暂停或恢复翻译，支持隐藏到托盘后台运行。
- 捕获完成后切窗或继续输入，翻译仍会继续，完成后交付剪贴板。
- 保持同一输入框且未编辑时，核对原文后原位替换；不会自动发送消息。
- 保护数字、日期、型号及金额币种，拒绝空译文和损坏的保护信息，不做汇率换算。
- 内置少量常用整句短语；剪贴板交付失败时可从托盘重试复制。

本版不包含自定义词库导入、多语种选择和一键日志导出，这些功能位于 1.1.0 Preview。

## 使用方法

1. 使用 Windows 10 / 11 x64，准备好本机 Ollama、本地模型和 .NET 8 Windows Desktop Runtime x64。
2. 完整解压发布包，保留 EXE、DLL、deps.json、runtimeconfig.json 四个文件。
3. 退出旧版后运行 `SpaceTranslate.exe`，需要时点击“准备模型”，等待就绪后隐藏到后台。
4. 在记事本先试中文双空格翻译；快捷键翻译前请选中文字。中文输入法完成选词后再触发双空格。
5. 看到剪贴板交付提示后，按 Ctrl+V 手动粘贴并核对内容。

配置位置为 `%LOCALAPPDATA%\SpaceTranslate\settings.json`，可通过主窗口“编辑配置”打开。已有用户沿用原配置；新建配置默认模型为 `qwen3:4b`，此前主要实测使用 `qwen2.5:7b`，两者不要混为同一配置。首次模型下载需要网络，已准备的本地模型可以离线使用。
